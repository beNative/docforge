# Release Notes - v0.9.7

## Code Editor Focus Stability & Mermaid Error Isolation

This maintenance release resolves critical editor input responsiveness regressions, hardens diagram rendering against DOM pollution, and fixes cross-platform test script execution.

### 🐛 Bug Fixes & Stability

#### Code Editor Focus Preservation on Text Entry
- **Eliminated Keystroke Focus Loss**: Fixed a critical regression where entering the first character into the Monaco code editor or diff editor caused immediate focus loss and blurred the cursor.
- **Reference Stabilization**: Wrapped and stabilized callback references (`onManualSave`, `onSaveToFile`, `onChange`, `onScroll`, `onFocusChange`, `onSelectionChange`) using mutable React refs in `CodeEditor`, `PromptEditor`, and `MonacoDiffEditor`.
- **Decoupled Editor Lifecycle**: Prevented unnecessary Monaco editor mounting, teardown, container detaching, or shortcut re-registration during text entry and state transitions.

#### Mermaid Syntax Error DOM Pollution Fix
- **Prevent Body Pollution**: Prevented Mermaid from injecting unstyled, intrusive "Syntax error in text" bomb SVGs into `document.body` when diagram syntax is invalid.
- **Pre-Validation & Isolation**: Enabled `suppressErrorRendering: true`, pre-validated syntax with `mermaid.parse()`, rendered into detached containers, and added active cleanup and CSS containment rules (`body > svg[id^="mermaid-"] { display: none !important; }`) to isolate diagram errors cleanly within the preview pane error card without distorting the application layout.

#### Cross-Platform Test Execution
- **Path Resolution Fix**: Resolved Windows path prefix resolution in the GUI test plan validation script using `fileURLToPath`.
