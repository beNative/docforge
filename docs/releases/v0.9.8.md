# Release Notes - v0.9.8

## Error Isolation Boundaries & Global Crash Diagnostics

This release introduces comprehensive component-level error boundaries, global uncaught exception logging to disk, safe context fallbacks, and hardened document preview rendering.

### 🛡️ Resilience & Fault Isolation

#### Component-Level Error Boundaries
- **Isolated Failure Recovery**: Introduced a resilient `ErrorBoundary` component featuring structured error messaging, context diagnostics (document name, ID, type, and language), retry mechanisms, and one-click copy-to-clipboard error details.
- **Granular Boundary Hierarchy**: Wrapped the root application, main document layout, code editor, and preview panes in discrete error boundaries. If an unexpected error occurs while rendering a specific document or preview component, the error is contained locally, allowing users to continue navigating and working across other tabs and documents without a blank window or application crash.
- **Automatic Main Process Log Syncing**: Component errors caught by `ErrorBoundary` are automatically dispatched to the persistent log file on disk via `window.electronAPI.log`.

### 🐛 Bug Fixes & Stability

#### Global Uncaught Exception & Promise Rejection Logging
- **Persistent Error Diagnostics**: Registered global window error and unhandled promise rejection handlers in `index.tsx` that forward detailed error stacks and messages to the application log file on disk.

#### Safe Icon Context Fallback
- **Default Iconset Fallback**: Updated `useIconSet` to provide a safe default icon set (`heroicons`) rather than throwing an uncaught exception when accessed outside an `IconProvider` hierarchy.

#### Navigation Diagnostics & Image Preview Hardening
- **Structured Navigation Logging**: Added detailed debug logging for document selection and tab activation events, including node ID, document type, and language hint.
- **Image Document Preview Test Coverage**: Added dedicated test suites for image document rendering, base64 PNG decoding, and error boundary recovery workflows.
