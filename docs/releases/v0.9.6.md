# Release Notes - v0.9.6

## Multi-Format Export & Navigation Polish

This release introduces multi-format export capabilities for PlantUML diagrams and Markdown documents, expanded treeview keyboard navigation, and key stability and UX fixes.

### ✨ Features

#### PlantUML Multi-Format Export
- **Export Formats**: Save diagrams directly as **PNG**, **SVG**, **JPEG**, or raw **PUML** source.
- **Dual-Engine Rendering**: Leverages local Electron Java rendering when available, with automatic fallback to the official remote PlantUML SVG service.
- **High-DPI Rasterizer**: Renders sharp 2x scaled images with transparent backgrounds for PNG and solid white backgrounds for JPEG.

#### Markdown Standalone HTML Export
- **Offline HTML Documents**: Export any Markdown document as a standalone, zero-dependency HTML file (`.html`).
- **Bundled Styling**: Includes responsive typography, GitHub-styled code blocks, tables, and blockquotes that look great in any browser without external CSS or fonts.

#### Export UI & Context Menus
- **Smart Toolbar Dropdown**: The editor toolbar features a new export dropdown that adapts available formats based on the active document type.
- **Context Menu Integration**: Direct export options are available in the document treeview context menu (*Save as HTML...*, *Save as PNG...*, *Save as SVG...*, *Save as JPEG...*).

#### Treeview Keyboard Navigation
- **Extended Keys**: Navigate your workspace hierarchy with `Home`, `End`, `PageUp`, and `PageDown` in addition to arrow keys.
- **Range Selection**: Select continuous blocks of documents with `Shift+Home`, `Shift+End`, `Shift+PageUp`, and `Shift+PageDown`.

#### Web Link Creation & Management
- **Manual Creation Modal**: Create web links directly via the sidebar toolbar button (`GlobeIcon`), context menus, or the `new-weblink` command.
- **Smart Title Derivation**: Automatically proposes human-readable titles derived from target URLs.

#### Status Bar & Save State Feedback
- **Active Document Version**: The status bar now displays the active document's current version (e.g. `v3`) next to the last save time.
- **Manual Save Feedback**: `Ctrl+S` commits a new document version with real-time toolbar feedback (dirty indicator, animated spinner, and green checkmark).

### 🐛 Bug Fixes

- **Template Navigation Isolation**: Fixed an issue where keyboard navigation scrolled into template items even when the templates panel was collapsed.
- **Drag-Drop Freeze Prevention**: Hardened URL drop extraction against large HTML payloads by bounding inspect size to 32 KB, replacing unbounded regex parsing with safe `DOMParser`, and enforcing scheme validation.
- **Local Embedded Browser Support**: Fixed white screens on `localhost` and `127.0.0.1` by permitting local self-signed certificates and scoping top-level navigation listeners away from `<webview>`.
- **Image Node Zoom**: Fixed zoom controls and wheel zooming on image documents by correctly routing zoom targets to the preview container.
- **Code Window Zoom**: Enabled Monaco editor mouse wheel zoom (`Ctrl + Wheel`) and smooth font scaling without reinitializing editor instances.
